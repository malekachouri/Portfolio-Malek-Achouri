# Achouri Malek - DevOps Portfolio

Crafted by Achouri Malek, this site distills DevOps mastery into a clean, fast experience—one scroll shows the skills, tools, and projects powering real-world cloud solutions.

## 🚀 Technologies Used
- React + Vite
- Tailwind CSS
- Dark Mode Support
- Netlify for Deployment

## 📂 Folder Structure
```
public/assets
src/
  components/
  pages/
  App.jsx
  main.jsx
index.css
```

## 🔧 Getting Started
```bash
npm install
npm run dev
```

## 📦 Build
```bash
npm run build
```

## 🌐 Deployment
Deployed using Netlify. Ensure `dist/` is published.
